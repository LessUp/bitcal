# 白皮书性能兼容说明

性能现在是独立一级 section，不再作为白皮书的附属子章节。

这个页面是旧 `/zh/whitepaper/performance` 链接的兼容入口。

请改走独立的 [Performance](/zh/performance/index) 路径，那里会分别说明：

- 当前保留的 baseline 快照；
- 测量方法学与复现命令；
- 宣称边界与解释护栏。

如果你原本想看的是设计论证，请回到 [白皮书入口](/zh/whitepaper/index)。白皮书继续负责设计论证；性能章节负责发布证据并限制证据的含义。
